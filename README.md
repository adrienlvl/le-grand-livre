# Le Grand Livre — version en ligne

Application de préparation au **Titre professionnel Comptable assistant** (niveau 4) et au BTS CG.

- Utilisable dans le navigateur : https://adrienlvl.github.io/le-grand-livre/
- Ce dépôt sert aussi de source de **mise à jour automatique** pour l'application Windows : au lancement, elle télécharge `le-grand-livre-compta.html`, vérifie sa signature Ed25519 (`.sig`) et l'adopte si elle est plus récente.

Ce dépôt ne contient que les fichiers publics de l'app. Aucune donnée personnelle : la progression reste enregistrée localement sur chaque appareil.
